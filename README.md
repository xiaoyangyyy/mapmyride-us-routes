# US City Activity Routes (GPX)

Public MapMyRide routes for 50 US cities: **685,482 routes**. Each city is searched from its center with a **50 km** radius.

The track files are not stored in this repository. Each city is one zip on [Release v1](https://github.com/xiaoyangyyy/mapmyride-us-routes/releases/tag/v1).

A zip unpacks to one city folder. Inside it, routes are grouped by activity, and there is a `路线清单.csv` index.

Common activity folders:

| Folder | Activity |
| --- | --- |
| 骑行 | Cycling |
| 公路骑行 | Road cycling |
| 山地骑行 | Mountain biking |
| 跑步 | Running |
| 越野跑 | Trail running |
| 步行 | Walking |
| 徒步 | Hiking |
| 划船 | Rowing |
| 皮划艇 | Kayaking |

Other activities use their own folders, named in English.

CSV columns: `路线id` (route id), `名称` (name), `活动id` (activity id), `活动目录` (activity folder), `距离米` (distance in meters), `描述` (description), `文件` (file).

## 中文

这些是 MapMyRide 上的公开路线，共 50 个美国城市、685,482 条。每个城市以市中心为圆心，搜索半径 50 公里。

轨迹不在仓库正文里，每个城市一个压缩包，在 [Release v1](https://github.com/xiaoyangyyy/mapmyride-us-routes/releases/tag/v1)。

解压后是城市文件夹，里面按活动类型分子文件夹，并有一份 `路线清单.csv`。常见目录：骑行、公路骑行、山地骑行、跑步、越野跑、步行、徒步、划船、皮划艇。其他活动使用英文目录名。

清单列：路线 id、名称、活动 id、活动目录、距离（米）、描述、文件。城市与路线数见上方英文表格。
