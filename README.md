# 美国城市运动路线（GPX）

这些是 MapMyRide 上的公开路线，共 50 个城市、685,482 条。每个城市以市中心为圆心，搜索半径 50 公里。

轨迹文件不在这个仓库里。每个城市一个压缩包，挂在 [Release v1](https://github.com/xiaoyangyyy/mapmyride-us-routes/releases/tag/v1)。

解压后是城市文件夹。下面按活动类型再分子文件夹（如骑行、公路骑行、山地骑行、跑步、越野跑、步行、徒步、划船、皮划艇），并有一份 `路线清单.csv`。
